Veropt

The Versatile Optimizer | View on GitHub →

Veropt is a Python package that tailors Bayesian optimization to climate science problems. It consists of three modules: optimizer core, interfaces and plotting tools. While working on the optimization experiments in Mrozowska et al. (2025), together with James Avery, I developed a wrapper for the optimizer core that supported a systematic and reproducible experimental pipeline. This code was then refactored and became the interfaces module.

The current version of Veropt was developed by me, James Avery and Aster Stoustrup, and my teammates' extensive experience with scientific computing and software development taught me a great deal about good coding practices and what it takes to launch a Python package for a diverse user base.
